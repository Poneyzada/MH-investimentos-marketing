# Estratégia de Marketing Digital — MH Investimentos
**Desenvolvido por Xcompany**

Proposta executiva de alta conversão estruturada em formato Landing Page interativa para apresentação e captação de clientes para a MH Investimentos.

## 🚀 Como Visualizar
Basta abrir o arquivo index.html em qualquer navegador web ou subir diretamente para a **Vercel** / **GitHub Pages**.

## 📊 Estrutura dos 5 Pilares
- **Pilar 1:** Tecnologia com Humanização (Chatbot IA empática, personas, vídeos com rosto humano, WhatsApp)
- **Pilar 2:** Geração de Indicações e Buzz (Moeda social, gatilhos sazonais, storytelling, bônus de indicação)
- **Pilar 3:** Crescimento Rápido e Enxuto (LPs segmentadas, A/B Testing, parcerias B2B, remarketing)
- **Pilar 4:** Retenção e Fidelização (Hook Model: Gatilho -> Ação -> Recompensa Variável -> Vínculo progressivo)
- **Pilar 5:** Seleção Estratégica de Canais (Facebook Ads, Instagram/TikTok, WhatsApp Business, Google Ads, B2B, SEO)

## 🛠️ Tecnologias Utilizadas
- HTML5 Semântico
- Tailwind CSS via CDN
- Lucide Icons
- Design responsivo, moderno e luxuoso (Dark & Gold) alinhado com a identidade da Xcompany
